Buttons

Use stil-btn on a <button> for actions, or on an <a> for navigation that looks like a button. Without a variant class a button is primary.

Variants

Outline and ghost

For less prominent actions. The variant color is used for the text and is readable in both color modes.

Sizes and icon buttons

stil-btn-icon makes a square button for a single glyph. Give it an aria-label.

Disabled and loading

Disable a button with disabled, or a link with aria-disabled="true" (and no href). Set aria-busy="true" while an action runs: the label is replaced by a spinner but stays available to screen readers.

Utilities

Single-purpose classes for spacing, display, flexbox, text, borders, shadows and sizing. Responsive versions are named stil-{utility}-{sm|md|lg|xl}-{value} and apply from that breakpoint up, for example stil-d-md-none or stil-gap-lg-5.

Spacing

stil-m-* (margin) and stil-p-* (padding) take a value from 0 to 7, and margins also take auto. Add a side: t, b, s (start), e (end), x (both sides) or y (top and bottom).
